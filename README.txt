WALAA ALNAABI — PORTFOLIO V2
================================

تشغيل الموقع
------------
1. افتحي هذا المجلد كاملًا في Visual Studio Code.
2. افتحي index.html.
3. اضغطي بزر الفأرة الأيمن واختاري Open with Live Server.

محتوى النسخة
------------
- Hero Section
- About Section متجاوب مع الهاتف والتابلت والكمبيوتر
- بطاقة صورة عائمة مع حركة خفيفة وتأثير ميلان بالفأرة
- Gallery Section يحتوي على 16 صورة WebP محسّنة
- Footer بسيط

الصور
-----
- جميع الصور داخل images/projects هي WebP حقيقية.
- أقصى ضلع للصورة 1600px تقريبًا.
- لا تغيّري الامتداد يدويًا؛ استخدمي XnConvert لإضافة صور جديدة.
- الملفات pic_2 وpic_9 وpic_10 وpic_13 وpic_17 لم تُضمّن لأنها كانت
  ملفات RAW للكاميرا وليست صور WebP صالحة للمتصفح في النسخة القديمة.

إضافة صورة جديدة للمعرض
-----------------------
1. حوّلي الصورة إلى WebP واكتبي الامتداد بحروف صغيرة: .webp
2. ضعيها داخل images/projects.
3. افتحي js/gallery.js.
4. أضيفي عنصرًا جديدًا داخل galleryItems مستخدمة نفس ترتيب العناصر الموجودة.

ملاحظات الحركة
--------------
- حركة البطاقة تعمل تلقائيًا بشكل هادئ.
- عند استخدام الفأرة تميل البطاقة قليلًا حسب اتجاه المؤشر.
- على أجهزة اللمس تبقى الحركة العائمة فقط.
- إذا فعّل المستخدم Reduce Motion في جهازه، تتوقف الحركات تلقائيًا.
